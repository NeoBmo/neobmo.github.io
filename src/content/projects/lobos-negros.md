Lobos Negros es el sitio de un club de taekwondo y mi proyecto más personal.

Está hecho con HTML, CSS y JavaScript puros, sin frameworks ni paso de compilación. Con él quiero mostrar que esos tres lenguajes todavía bastan para una tarjeta de presentación que impresione y para la página de un negocio pequeño.
